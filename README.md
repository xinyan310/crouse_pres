# 中国式现代化课堂展示：杭州低碳科技馆实地调研

本仓库用于整理“中国式现代化”课程的实地调研材料、分析成果与课堂展示内容，以杭州低碳科技馆参观调研为切入点，探讨人与自然和谐共生的现代化。

> 资料状态：目前尚未导入实地照片、视频及展板文字，以下内容是整理框架与展示建议，不代表已经核实的展馆事实。场馆正式名称、展区名称、参观时间及具体展项均待依据原始资料确认。

## 一、调研主题与问题

**建议题目：从低碳科普到绿色生活——中国式现代化视域下的杭州低碳科技馆调研。**

围绕以下问题收集证据并形成分析：

1. 展馆如何解释气候变化、碳排放与低碳发展的关系？
2. 展馆通过哪些展项或互动方式，将绿色发展理念转化为公众能够理解的知识？
3. 展示内容如何联系能源、交通、建筑、消费等日常生活场景？
4. 低碳科普如何帮助理解人与自然和谐共生的现代化？
5. 从参观体验看，展馆在知识传播、公众参与和行动引导方面有哪些值得讨论的地方？

## 三、分析框架

以“现场证据—展示机制—课程概念—调研判断”为基本结构，避免只罗列照片或仅复述理论。

| 分析角度 | 需要寻找的现场证据 | 可讨论的课程联系 |
| --- | --- | --- |
| 生态文明与绿色发展 | 经核实的生态环境、碳循环或低碳生活展项 | 人与自然和谐共生的现代化 |
| 科技创新与绿色转型 | 经核实的清洁能源、节能技术等展示 | 创新如何支持发展方式转变 |
| 公共科普与公众参与 | 互动装置、讲解活动及实际参与记录 | 公众科学素养与绿色行动 |
| 城市治理与日常生活 | 经核实的交通、建筑、资源利用等案例 | 绿色发展理念如何落实到生活场景 |

上述展项类别仅作为检索方向，不能在材料核实前写成场馆实际设置。对单次参观形成的判断，应明确观察范围，避免推断全部参观者或整个城市的成效。

## 四、课堂展示建议

以下按约 10 分钟设计，可依据课程要求调整。

| 环节 | 建议时长 | 主要内容 |
| --- | --- | --- |
| 问题导入 | 1 分钟 | 用一张现场照片提出“低碳与现代化有什么关系” |
| 调研概况 | 1 分钟 | 交代时间、地点、成员、方法与资料范围 |
| 典型展项分析 | 4 分钟 | 选择 2—3 个已核实案例，逐一说明现场证据及课程联系 |
| 发现与反思 | 2 分钟 | 分析知识传播、体验参与与行动引导，说明观察局限 |
| 结论与讨论 | 2 分钟 | 回答调研问题，提出有依据的建议并邀请课堂讨论 |

建议 PPT 页序：封面 → 调研问题 → 方法与路线 → 典型案例一 → 典型案例二 → 综合分析 → 反思与建议 → 结论及参考资料。

每个案例页尽量包含一张清晰现场照片、一段准确的展项说明和一个有证据支撑的判断。照片注明素材编号；引用的数据、政策原文与观点注明来源。
